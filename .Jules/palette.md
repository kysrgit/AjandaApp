## 2025-02-18 - Non-semantic Tags for Interactive Elements
**Learning:** The application uses non-semantic HTML tags (like `div`) for interactive UI components such as `.workout-badge.clickable`. This lack of native semantics inherently degrades keyboard navigation and screen reader support, preventing users relying on assistive technologies from effectively discovering or interacting with key features like the fitness modal.
**Action:** When working on this repository, I must pro-actively identify click-enabled non-semantic tags and explicitly enhance them with `role="button"`, `tabindex="0"`, and custom `keydown` handlers (specifically covering `Enter` and `Space`, while using `e.preventDefault()` to stop spacebar page scrolling) to ensure they meet basic accessibility standards.
