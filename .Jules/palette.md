## 2024-05-24 - Interactive Non-Semantic Elements Require Explicit Keyboard Event Handlers
**Learning:** In this application, custom interactive elements (like the `.workout-badge.clickable` divs) often lack built-in semantic attributes. Simply adding `role="button"` and `tabindex="0"` allows them to be focusable via the keyboard, but they still require explicit event listeners for 'Enter' and 'Space' keypresses to trigger the associated action, mimicking native button behavior. Furthermore, preventing default scrolling action upon 'Space' presses is necessary for these types of custom elements to function correctly as interactable items.
**Action:** When creating or identifying custom interactive elements using non-semantic tags (e.g., `div` or `span`) across the codebase, always ensure they are paired with `role="button"`, `tabindex="0"`, and `keydown` event listeners that explicitly handle `Enter` and `Space` keys (including `e.preventDefault()`), ensuring full accessibility.
