## 2024-04-28 - Missing keyboard focus & ARIA labels
**Learning:** Found an accessibility issue pattern in this app's UI where interactive elements (inputs, textareas) use `outline: none` to suppress default browser outlines, which removes keyboard focus visibility if custom focus styles (`box-shadow`, `border-color`) don't provide sufficient contrast or aren't explicitly defined for all elements. Additionally, icon-only buttons lacked descriptive `aria-label`s, hindering screen reader support.
**Action:** Always add a global `:focus-visible` fallback (e.g., `outline: 2px solid var(--fitness-color); outline-offset: 2px;`) to interactive elements to ensure reliable keyboard navigation visibility, and enforce `aria-label`s on all icon-only interactive components during initial implementation.
