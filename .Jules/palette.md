## 2024-05-24 - Accessibility and Focus Management in Dynamic UI
**Learning:** In applications heavily relying on dynamic DOM insertion (like `innerHTML` templating or `document.createElement`), native accessibility features such as `aria-label` are easily overlooked on icon-only buttons compared to static HTML. Furthermore, custom component classes suppressing default outlines (`outline: none`) without explicit `:focus-visible` states critically impairs keyboard navigation.
**Action:** Always proactively review Javascript file templates for missing ARIA properties on dynamically injected interactive elements. Enforce a global `:where()` based `:focus-visible` rule rather than component-specific focus states to ensure uniform keyboard accessibility across the entire app without relying on `!important` anti-patterns.
