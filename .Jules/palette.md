## 2026-04-02 - Keyboard Accessibility for Non-Semantic Interactive Elements
**Learning:** The application uses non-semantic `div` tags for interactive elements (like `.workout-badge.clickable`). While visually these act as buttons opening modals, they natively lack screen reader roles and keyboard accessibility (focus states, `tabindex`, and activation via 'Enter' and 'Space' keys), which prevents keyboard-only users from interacting with them. Adding an 'Enter'/'Space' handler requires an explicit `e.preventDefault()` on the Space key to stop the browser from scrolling down.
**Action:** When creating custom interactive widgets using `div` or `span`, always explicitly add `role="button"`, `tabindex="0"`, keyboard event listeners ('Enter', 'Space' with preventDefault), and verify focus-visible styles exist globally to ensure they match native `<button>` accessibility behavior.
