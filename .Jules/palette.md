## 2024-05-22 - Keyboard Accessibility for Hover Actions
**Learning:** Interactive elements that only appear on hover (like the day edit button) are invisible to keyboard-only users.
**Action:** Always add `:focus-visible` styles to match hover states for hidden actions, ensuring `opacity: 1` and visible focus indicators.
